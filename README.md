# 音感トレーニング — 紹介ページ（LP）

自作アプリ「音感トレーニング（アドリブへの耳をつくる）」の紹介ページです。
「Webページを作って公開するまで」を体験・理解するための練習も兼ねています。

## フォルダの構造（＝Webページの基本構造）

```
web_lp/
├─ index.html      … 中身（何を書くか）。ブラウザが最初に開くファイル
├─ css/style.css   … 見た目（色・余白・文字）。index.html の <head> で読み込む
├─ js/main.js      … 動き（音を鳴らす）。index.html の </body> 直前で読み込む
├─ images/         … 画像（アプリのスクリーンショット、WebP形式）
├─ favicon.svg     … ブラウザのタブに出る小さなアイコン
└─ README.md       … この説明書き（ページには表示されない）
```

「中身（HTML）・見た目（CSS）・動き（JS）」を別ファイルに分けるのがWebの基本形。
1枚に全部書くこともできる（第1版はそうだった）が、分けておくと直す場所が迷わない。

## 手元で見る

`index.html` をダブルクリックするだけ（ネット接続はフォント読み込みにだけ使う）。

## 直して公開する（毎回この4手順）

1. ファイルを直す（文言なら `index.html`、色や余白なら `css/style.css`）
2. `git add -A` … 変更を「次に記録するもの」として選ぶ
3. `git commit -m "何を直したか"` … 変更を1つの記録として残す
4. `git push` … GitHub（インターネット上の置き場所）に送る → 1〜2分でページに反映

## 注意

- このフォルダの中身は **まるごと公開される**。公開したくないファイルは置かない。
- 個人情報（住所・電話・本名など）や、他人の著作物（教材・写真）は載せない。
